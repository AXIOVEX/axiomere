# Naming Record — Axiomere, `.axmr`, Tekmerion

**Date:** 2026-10-11 · **Decided by:** analysis + owner direction (the database name must use "axiom"; all artifacts MIT; naming verified before any framework work continues)

## The database: **Axiomere**

*axiom* + Greek **μέρος (meros)** — a part, a unit, a segment (as in *metamere*, *polymer*). An axiomere is one indivisible unit of asserted truth; a ledger is units chained in order, each one signed, scored, and impossible to remove — only superseded by a later unit or declared dead. Pronounced *ax-ee-OH-meer*.

**Category language:** Axiomere is a **truth ledger**. "Database" is retained only as a plain descriptor (people search for it); it is not the category claim — a database's defining verbs include update and delete, and Axiomere's defining property is that those verbs do not exist.

## The file extension: **`.axmr`**

One ledger = one file, `name.axmr`, beginning with the 8-byte magic line `AXMR1`. No registered file format uses `.axmr` (checked 2026-10-11; prior uses of the string are a lighting product code and an acronym, not a format). The magic header, not the extension, is authoritative — verification rejects any file without it.

## The framework: **Tekmerion**

The research framework that runs on Axiomere is named **Tekmerion** (τεκμήριον, *tek-MEER-ee-on*) — the classical Greek term for *conclusive evidence: a sure sign by which a thing is proved*. It is what the framework produces: not summaries, but evidence that can carry a verdict. Checked 2026-10-11: no PyPI package; a handful of small unrelated GitHub repositories; no software product. The framework's existing repository (currently `AXIOVEX/research-engine`) will be renamed `AXIOVEX/tekmerion` as the first step when framework work resumes, with the rename recorded in that repo's design notes.

*Scope note: these checks cover the public registries and the indexed web as of the date above. They are strong evidence of uniqueness, not a trademark clearance; a formal trademark search is a separate, owner-gated step before any commercial launch.*
